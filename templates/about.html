About Odisha FRA Monitoring System

A data-driven platform for monitoring and analysing Forest Rights Act implementation across Odisha.

Academic Project

Project Overview

The Odisha FRA Monitoring System is a data-driven monitoring and analytical platform designed to organize, explore and analyse Forest Rights Act (FRA) implementation-related information across Odisha.

The system combines data processing, data visualization and machine learning techniques to provide insights into district-level implementation statistics and village-level beneficiary distribution.

🌳

Forest Rights Act

FRA, 2006

Problem Statement

Forest Rights Act implementation data is available across different records and administrative sources. Analysing this information can be challenging without a centralized platform.

This project aims to organize the available data into a structured system that supports district monitoring, village-level exploration, analytical classification and geographical visualization.

Project Objectives

01. Data Integration

Organize and combine available FRA-related district and village-level datasets.

02. Data Analysis

Analyse beneficiary distribution and district-level implementation statistics.

03. Machine Learning

Apply clustering algorithms to identify analytical groups among village records.

04. Geographical Visualization

Provide a geographical interface for exploring Odisha and future GIS data layers.

05. Reporting

Allow users to explore and download available monitoring and analytical datasets.

06. Monitoring Support

Present structured information to support data exploration and analytical understanding.

Key Features

Module Description
Dashboard Displays overall district and village statistics through cards, charts and tables.
District Analytics Provides district-wise FRA implementation statistics and monitoring information.
ML Priority Analysis Presents K-Means and Hierarchical clustering results with model evaluation.
WebGIS Map Provides an interactive geographical base map using Leaflet and OpenStreetMap.
Village Explorer Allows users to search and explore village-level beneficiary information.
Reports Provides downloadable district, village and clustering datasets.

Machine Learning Methodology

Clustering techniques are applied to village-level numerical features to identify analytical groups.

Step 01

Data preparation and feature engineering.

Step 02

Feature scaling using StandardScaler.

Step 03

K-Means and Hierarchical clustering.

Step 04

Model evaluation and PCA analysis.

Important: Machine learning cluster labels and village monitoring categories are analytical classifications. They are not official government FRA implementation priority labels.

Data Scope and Limitations

  • The system uses the available project datasets for district and village-level analysis.
  • Village beneficiary counts should not be interpreted as verified village-level approved, rejected or pending claims.
  • Machine learning clusters represent analytical groupings based on selected numerical features.
  • The current WebGIS page displays a geographical base map. Verified FRA village coordinates and district boundary layers are pending integration.
  • Analytical monitoring indicators should not be treated as official government records.
