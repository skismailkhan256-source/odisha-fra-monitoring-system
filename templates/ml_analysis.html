MODEL DEVELOPMENT PROCESS

ML Methodology

Key steps followed in the clustering and analysis workflow.

01
Feature Selection

Selected four village-level numerical features: Beneficiary Count, Village Share in GP, Village Share in Block and Village Share in District.

02
Feature Scaling

Applied StandardScaler for feature scaling.

03
K-Means Clustering

Applied K-Means clustering with 5 clusters.

04
Hierarchical Clustering

Applied Hierarchical clustering with 6 clusters.

05
Model Evaluation

Evaluated both clustering models using Silhouette Score, Davies-Bouldin Index and Calinski-Harabasz Score.

06
Dimensionality Reduction

Used PCA to reduce feature dimensions for visualization.

Analytical Interpretation

Cluster labels represent analytical groups based on village-level features. They should not be interpreted directly as official government FRA implementation priorities.
